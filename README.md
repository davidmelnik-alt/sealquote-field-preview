# SealQuote Field Preview
Standalone, browser-only driveway estimator for contractor feedback. The public site opens directly to the estimate. No accounts, estimate history, or server-side draft storage. Download a text quote or use Print / Save PDF before leaving. Aerial lookup uses U.S. Census geocoding and USGS imagery.

The editable Vite/React app is in source/. From that directory, run npm ci and npm run build with Node 22.13+; copy the generated dist/ contents to the repository root to publish an update. Only the standalone preview lives in this repository.
